# The Loud Standard

Plain-language notes on cannabis for Canadian adults: strains, gear, and how-tos.

This folder is a static GitHub Pages site for the article "Gift Ideas for Cannabis Lovers".

## Publish (after the account exists)

1. Create a GitHub account with theloudstandard@gmail.com.
2. Suggested username: theloudstandard. Fallbacks: loudstandard, the-loud-standard, loudstandardca, tlsnotes.
3. Create a public repository named `theloudstandard.github.io` for a user site, or any public repo if you prefer a project site.
4. Upload every file in this folder, including `assets/style.css`, to the default branch (usually `main`).
5. In the repo, open Settings, then Pages. Set the source to the default branch, folder `/ (root)`, and save.
6. Wait a minute, then open https://theloudstandard.github.io/ (user site) or https://USERNAME.github.io/REPO/ (project site).
7. Confirm the title, the body, and that the site has no shop link.

`index.html` is a complete page and works with Pages set to deploy static files from the root. `_config.yml` and `index.md` are included if you later switch the repo to Jekyll. Use one or the other, not both as competing homepages, if you enable Jekyll.

Stop if GitHub asks for a phone number. Do not add a card. Do not add a shop URL.
